# 🏠 Prop_Vision

Prop_Vision is a modern property management mobile application developed using Kotlin for Android. The application allows users to buy, sell, and rent houses through an easy-to-use and user-friendly interface. The project focuses on simplifying real estate interactions with advanced search functionality, organized property listings, and smooth mobile navigation.

---

## 🚀 Features

- 🔍 Search properties with filters
- 🏡 Buy, Sell, and Rent houses
- 📱 User-friendly mobile interface
- 🗂️ Property listing management
- ❤️ Save favorite properties
- 📍 Location-based property browsing
- 🔐 Secure user authentication
- ☁️ Firebase integration
- 📷 Property image uploads
- 📞 Contact property owners

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Hamza-saleem-pro/Prop-Vision.git
```

### 2️⃣ Open in Android Studio

- Open Android Studio
- Click on **Open Project**
- Select the cloned folder

### 3️⃣ Connect Firebase

- Create Firebase project
- Add `google-services.json`
- Enable Authentication & Database

### 4️⃣ Run Application

```bash
Run ▶️
```
